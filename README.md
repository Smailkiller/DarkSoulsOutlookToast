# DarkSoulsOutlookToast

VSTO-надстройка для Microsoft Outlook, которая заменяет стандартные уведомления о письмах на кинематографичные оверлеи в стилистике Dark Souls.

Проект создан как эксперимент с визуальными эффектами и пользовательским опытом: вместо обычных системных уведомлений вы получаете атмосферную тёмную плашку, анимацию текста и кастомные звуки при получении и отправке писем.

---


## Технические детали

- Тип проекта: **VSTO Add-in для Outlook**
- Язык: **C#**
- UI: **Windows Forms (кастомная отрисовка через GDI+)**
- Поддержка: **Outlook x64**
- Платформа: **.NET Framework (VSTO)**

Оверлей реализован как отдельное topmost-окно без рамок, с ручной отрисовкой анимаций и эффектов.  
Проект не использует WPF или внешние UI-фреймворки.

---

## Установка

### Требования
- Microsoft Outlook (x64)
- Microsoft Visual Studio Tools for Office Runtime
- Windows 10 / 11

### Установка надстройки
1. Перейдите в раздел **Releases** или папку `publish`
2. Запустите `setup.exe`  
   *(или `DarkSoulsOutlookToast.vsto`, если VSTO Runtime уже установлен)*
3. Подтвердите установку
4. Перезапустите Outlook
